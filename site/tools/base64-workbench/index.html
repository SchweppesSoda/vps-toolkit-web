Base64 Workbench

本地离线 Base64 编解码台

这是一个单文件、本地可直接打开的 HTML 工具。除了标准 Base64 以外，还兼容 base64url、缺失补位、夹杂空白、脏字符过滤、自定义字母表，以及常见的 bcrypt / crypt 非标字母表。

宽松解码 可自动补齐 padding，并忽略换行、空格、数据头或杂字符。
非标兼容 支持 Standard、URL-safe、bcrypt、crypt、自定义 64 字符字母表。
多种输出 解码结果可看作 UTF-8 文本或 Hex，还能一键下载为二进制文件。

输入区

把普通文本、Hex、Base64 或奇怪变体贴进来

兼容设置

对各种非标 Base64 的容错和字母表映射
等待操作。

输出区

解码后的原始字节会保留在内存里，方便再次转换或下载
提示：如果解码结果不是合法 UTF-8，切换“解码后显示方式”为 Hex 更稳妥。若你碰到更偏门的变体，直接把 64 字符字母表填到 Custom 即可。
